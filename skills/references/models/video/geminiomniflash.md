# Gemini Omni Flash — `geminiomniflash`
**Provider:** Google (Vertex AI, Interactions API) · **Underlying model:** Gemini Omni Flash (`gemini-omni-flash-preview`) · **Modality:** Text-to-video, image-to-video, **and video-to-video editing** · **Audio:** native (generated by the model itself; no `--audio` toggle in rtst)

Google's natively multimodal video model: it reasons over text, images, and video *together*, which makes it the only rtst model that can **edit an existing video from a text instruction** — remove objects or people, swap the background, change the color grade or lighting, restyle the footage (e.g. to anime), add on-screen text/captions, or change the music and sound design — while keeping everything else intact. Also strong at reference-driven generation (up to 7 reference images) with good character consistency and real-world knowledge. Reach for it when the job is *editing or transforming footage*; for pure cinematic text-to-video quality at higher resolutions, prefer `seedance20` or `kling3`.

## rtst usage
```bash
# Generate
rtst video create geminiomniflash --prompt "..." --aspect-ratio 16:9 --duration 8 --wait --json

# Edit an existing video: pass it with --reference-video and address it as {{vid1}}
rtst video create geminiomniflash --reference-video ./clip.mp4 \
  --prompt "In {{vid1}}, remove the person walking in the background. Keep everything else the same." \
  --aspect-ratio 16:9 --duration 8 --wait --json
```

## Parameters (enforced by the rtst API)
- **Aspect ratios:** `16:9`, `9:16`
- **Resolutions:** `720p` only
- **Durations (s):** `3`–`10`
- **Audio:** generated natively by the model (music/SFX; steer it from the prompt); there is no `--audio` flag for this model
- **Image input:** `--first-frame`, `--last-frame`, `--reference-image` (repeatable, up to 7). This is a structured-reference model: inputs are **photo ids, not URLs** — the CLI uploads local files/URLs as Photos automatically.
- **Video input:** one `--reference-video` (local file, URL, or video-media id) — the source footage to edit. Max 1 video.
- **Prompt placeholders (required for references):** `{{img1}}`, `{{img2}}`, ... for reference images ({{first}}/{{last}} for frames, written as plain words) and `{{vid1}}` for the source video. Unmentioned references anchor nothing.

## How to prompt it

**Editing (its superpower): keep instructions short and surgical.** Google's own guidance: simple prompts work best for editing — overly descriptive prompts cause unintended changes. The reliable pattern:

> `In {{vid1}}, <one specific change>. Keep everything else the same.`

- **Object/person removal:** "remove the coffee cup from the table", "make the person in the background invisible".
- **Background replacement:** "replace the white wall behind the speaker with a forest at dusk".
- **Relight / color grade:** "change the color grade to golden hour", "make it look like an overcast morning".
- **Restyle:** "convert the whole video to hand-drawn anime style".
- **Captions / on-screen text:** spell out the exact text and where/when it appears: `add a bold white caption at the bottom that says "SUMMER SALE — 50% OFF" for the first 3 seconds`. Always quote the literal text you want rendered.
- **Timing:** reference moments in natural language or timecodes ("at 00:02", "in the final second").
- **Audio:** you can direct music/sound design ("replace the music with soft lo-fi"), but **voice editing is not supported**.

**Generation:** normal directorial prompting applies (subject → action → setting → camera → lighting/mood), and each reference image should be named in the prompt with its role: "the woman from {{img1}} wearing the jacket from {{img2}}".

## Example prompts

```bash
# 1. Remove an object from existing footage
rtst video create geminiomniflash --reference-video ./product-shot.mp4 \
  --prompt "In {{vid1}}, remove the cables visible on the desk. Keep everything else the same." \
  --aspect-ratio 16:9 --duration 6 --wait --json

# 2. Add a caption overlay
rtst video create geminiomniflash --reference-video ./promo.mp4 \
  --prompt 'In {{vid1}}, add a bold white caption at the bottom center that says "NEW ARRIVALS" for the first 3 seconds. Keep everything else the same.' \
  --aspect-ratio 9:16 --duration 8 --wait --json

# 3. Swap the background
rtst video create geminiomniflash --reference-video ./talking-head.mp4 \
  --prompt "In {{vid1}}, replace the plain wall behind the speaker with a blurred modern office. Keep the speaker, framing and lighting the same." \
  --aspect-ratio 16:9 --duration 10 --wait --json

# 4. Reference-driven generation (no source video)
rtst video create geminiomniflash --reference-image ./mascot.png \
  --prompt "The mascot from {{img1}} waves at the camera in a sunny park, gentle handheld camera, cheerful upbeat music" \
  --aspect-ratio 9:16 --duration 5 --wait --json
```

## Limitations & tips

- **One edit per generation** works best: chain generations for multiple changes (edit → download → feed the result back as the next `--reference-video`).
- Max **1 source video**; multi-video referencing is unsupported. No video extension or frame interpolation.
- Voice editing (changing spoken words) is not supported; other audio edits are.
- 720p only — if the edited clip must ship at higher resolution, upscale afterwards.
- Reference media are content-moderated (photos of public figures rejected); source videos are moderated too.
- Preview spend first: `rtst video cost geminiomniflash --duration 8 --resolution 720p` or add `--estimate` to your exact `create` command.
